This program sends my own make.fun username and nothing else — one word, no
explanation, no links, no pitch — for the make.fun bounty
[One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

Running `main.ts` (Node 22) writes the username `vr23zone-2` plus a trailing
newline to `/output/entry.txt` (11 characters total).
